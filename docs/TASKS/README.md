# Task briefs

One file per lesson still to rebuild. Each names the topics the lesson must cover, in the
order they should appear, with the non-obvious points called out in bold.

**To use one — directly or as an agent prompt:**

> Read `docs/LESSON_REBUILD_SPEC.md` and `docs/TASKS/<file>.md`, then rewrite that lesson.
> Do NOT run git. Do NOT edit `validate.py`. Validate with
> `python validate.py tutorials/<track> <lesson>.html` before you finish.

Delete a brief once its lesson is rebuilt and pushed.

Before writing, read the current file's `<div class="pager">` and reproduce it exactly — the
pager and `nav.js` must agree.
